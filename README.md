# 精選畫作 限量展售 | 畫廊風格藝術作品展售網站

畫廊風格的藝術作品展售網站,包含前台購物流程與後台管理系統,串接 API 取得 token 驗證,可管理商品與訂單。

[線上 Demo](https://hthoftt.github.io/react-vite-work1/)

## 功能
- 前台:依分類展示畫作(例如素描類)、購物車
- 後台登入:串接 API 取得 token 進行驗證
- 商品管理:可新增、編輯、刪除
- 訂單管理:可新增、編輯、刪除
- 後台介面使用 Bootstrap 模板
- 商品資料透過 API 取得
- 使用 Redux 管理狀態
